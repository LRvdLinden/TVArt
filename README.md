# TVArt · tvOS

Native Apple TV art gallery. Bundle identifier: `nl.lrvdlinden.tvart`. Version `1.0.0` (build `1`).

The full Xcode source project is delivered as `TVArt-v1.0.0-build1.zip` in the associated ChatGPT conversation. Open `TVArt.xcodeproj` with Xcode and select an Apple TV target. This repository README is an initial record; the full project source has not yet been uploaded to the repository.

Artwork providers: Art Institute of Chicago and Metropolitan Museum of Art public APIs. Verify image rights before commercial publication.
